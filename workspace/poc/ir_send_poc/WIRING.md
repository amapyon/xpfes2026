# OSI5FU3A11C 赤外線送信PoC 配線図

## 使用部品

| 部品 | 型番・値 | 購入先／備考 |
|---|---|---|
| 赤外線LED | OptoSupply `OSI5FU3A11C` | [秋月電子 商品番号104313](https://akizukidenshi.com/catalog/g/g104313/)、3mm、940nm、10個入り200円（税込、2026-08-14確認） |
| LED直列抵抗 | `82Ω、1/2W以上` | LEDごとに1本使用 |
| NチャネルMOSFET | `MTB30N06I3` | [秋月電子 商品情報](https://akizukidenshi.com/catalog/g/g115850/) |
| ゲート直列抵抗 | `100Ω、1/4W` | PC4－Gate間 |
| ゲートプルダウン抵抗 | `100kΩ、1/4W` | Gate－GND間 |

`OSI5FU3A11C`の主な仕様は、順方向電圧typ. 1.35V（100mA時）、連続順方向電流最大
100mA、ピーク波長940nm、放射強度typ. 40mW/sr（50mA時）、半値角15°です。
[メーカーのデータシート](https://akizukidenshi.com/goodsaffix/OSI5FU3A11C.pdf)も参照してください。

## 推奨回路（LED 1個）

```text
UIAPduino Pro Micro CH32V003 V1.4

  5V o----[ 82Ω / 1/2W ]----|>|----o D (pin 2)  MTB30N06I3
                            LED       |
                                      |
 D6/A2 / PC4 o----[100Ω]----------o G (pin 1)
                                      |
                                [100kΩ]
                                      |
 GND o----------------------------o S (pin 3)
   |                                  |
   +----------------------------------+
```

LEDは`pin 1=Anode`、`pin 2=Cathode`です。図の`|>|`は左がアノード、右がカソードです。
組み立て時は足の長短だけに頼らず、データシートまたはテスターでも確認してください。

`MTB30N06I3`は、印字面を正面にして足を下へ向けたとき左から
`pin 1=Gate、pin 2=Drain、pin 3=Source`です。型番末尾は数字の`13`ではなく英字の`I3`です。

## 抵抗値と電流

データシートの代表VF 1.35Vを使うと、LED電流は次の値になります。

- 5.00V時: `(5.00V - 1.35V) / 82Ω = 約44.5mA`
- 5.25V時: `(5.25V - 1.35V) / 82Ω = 約47.6mA`

放射強度が規定されている50mA付近を狙いつつ、連続最大100mAに余裕を持たせた値です。
VFには個体差と温度依存性があり、抵抗の瞬時損失は約0.19Wになるため、`1/2W以上`を
使用します。38kHz搬送波のDutyは約50%ですが、電流の安全確認には瞬時値を用います。

データシートのパルス順方向電流1Aは、パルス幅100µs以下かつDuty 1/100以下だけの定格です。
現在の約50% Dutyの搬送波には適用できないため、1Aを狙った抵抗値にはしません。

## 配線表

| 接続元 | 接続先 | 用途 |
|---|---|---|
| UIAPduino `5V` | `82Ω（1/2W以上）` → LED pin 1（Anode） | LED電源、約45～48mA |
| LED pin 2（Cathode） | MTB30N06I3 pin 2（Drain） | LED電流のスイッチ |
| UIAPduino `D6/A2` | `100Ω` → MOSFET pin 1（Gate） | `PC4 / TIM1_CH4`の38kHz出力 |
| MOSFET pin 1（Gate） | `100kΩ` → GND | 起動・未接続時のOFF保持 |
| MOSFET pin 3（Source） | GND | 電流帰路 |
| UIAPduino GND | 回路GND | 共通GND |

UIAPduinoのマイコン電源ジャンパーは5V設定にします。`MTB30N06I3`は`VGS=4.5V`で
オン抵抗最大45mΩが規定されています。USB HIDは`PD3 / PD4 / PD5`、赤外線搬送波は
`PC4 / TIM1_CH4`を使用するため競合しません。

## LEDを2個使う場合

到達距離が不足する場合は、LEDを並列2枝にして、各LEDへ個別に82Ωを入れます。

```text
5V ---[82Ω / 1/2W]---|>|---+
                           |
5V ---[82Ω / 1/2W]---|>|---+--- Drain (MTB30N06I3)
```

抵抗を2灯で共用してはいけません。各LEDは約45～48mA、MOSFETを流れる合計電流は
約90～96mAです。2個の光軸をエアコンの受光部へ合わせてください。

## 必須の安全確認

配線安全確認: **未確認**

1. USBを外した状態で作業する。
2. LEDが`OSI5FU3A11C`で、pin 1がAnode、pin 2がCathodeであることを確認する。
3. UIAPduinoのマイコン電源ジャンパーが5V設定であることを確認する。
4. MOSFETが`MTB30N06I3`で、正面からGate / Drain / Sourceの順であることを確認する。
5. `5V → 82Ω → LED → Drain → Source → GND`の順であることを確認する。
6. Gate-GND間が`100kΩ`、PC4-Gate間が`100Ω`であることを確認する。
7. 5V-GND間が短絡していないことを確認する。
8. 赤外線LEDを人の目へ向けない。

## 初回通電後の確認

1. エアコン受光部から10～30cm、ほぼ正面に置く。
2. スマートフォンのカメラで、送信時だけ発光することを確認する。
3. 受信PoCで、送信コードが純正リモコンのコードと一致することを確認する。
4. 問題がなければ距離を少しずつ延ばし、到達距離を記録する。
5. 発熱、臭い、USB切断があれば直ちにUSBケーブルを外す。
