# PART-08 赤外線受信PoC 配線図

## 確定配線

```text
PART-08 (VS1838B基板)                 UIAPduino Pro Micro CH32V003 V1.4

  VCC  o------------------------------o 5V
  GND  o------------------------------o GND
  OUT  o-----------[100 ohm]----------o D12 / A3 / PD2

  VCC  o----||----o GND
            0.1uF  （受信基板の近く。用意できる場合）
```

物理的な左・中央・右の順番はロットで判断せず、配布品の基板に印字された
`OUT / GND / VCC`を一本ずつ確認してください。100Ωは誤って出力同士が接続された
場合の電流を抑えるための直列保護抵抗です。

| PART-08 | UIAPduino | MCU端子 | 用途 |
|---|---|---|---|
| VCC | 5V | 電源 | センサー給電 |
| GND | GND | GND | 共通GND |
| OUT | D12 / A3 | PD2 / TIM1_CH1 | アクティブLowの復調信号 |

USB HIDは`PD3 / PD4 / PD5`、赤外線入力は`PD2 / TIM1_CH1`を使うため競合しません。
旧版の`D5 / PC3`配線ではUSB処理と外部割り込みが競合するため、必ず`D12 / A3`へ移してください。

この配線でNEC、NEC repeat、東芝エアコン72bitの実機受信を確認済みです。

## 初回だけ行う段階配線

1. USBを外し、UIAPduinoのマイコン電源ジャンパーが出荷時の5V設定であることを確認する。
2. PART-08の印字を確認し、最初は`VCC -> 5V`と`GND -> GND`だけを接続する。`OUT`はUIAPduinoから外しておく。
3. USBを接続し、テスターでPART-08の`GND-OUT`間を測る。待機時が0～5.0Vの範囲で、リモコン操作時も5.0Vを超えないことを確認する。
4. USBを外し、100Ωを介して`OUT -> D12 / A3`を接続する。
5. 配線を再確認してから書き込み・実機試験へ進む。

電圧が5.0Vを超える、端子印字がない、部品がVS1838Bでない、発熱・異臭・USB切断が
起きる場合は接続を中止してください。

## 配線後の確認

1. `make app`を起動し、待機時に`OUT=HIGH`と表示されることを確認する。
2. リモコンを操作し、`edges`が増加することを確認する。
3. NECまたは`TOSHIBA_AC`の16進数が表示され、`errors`が増えないことを確認する。
