# 配線

## 対象

- UIAPduino Pro Micro CH32V003 V1.4
- ドライバー回路内蔵の5V振動モーターモジュール
- モジュール端子: `VCC`、`GND`、`IN`

このPoCは**モーター本体をGPIOへ直接接続する構成ではありません**。

## 標準配線

配線変更前にUSBケーブルを外してください。

| UIAPduino | 振動モーターモジュール | 用途 |
|---|---|---|
| `5V` | `VCC` | モジュール電源 |
| `GND` | `GND` | 共通GND |
| `D6/A2` | `IN` | 振動制御信号 |

`D6/A2`はCH32V003の`PC4`で、PWM使用時は`TIM1_CH4`として使用します。

## 回路イメージ

```text
UIAPduino                         振動モーターモジュール

5V   ---------------------------> VCC
GND  ---------------------------> GND
D6/A2 (PC4 / TIM1_CH4) --------> IN
```

## デカップリング

プロジェクトのハードウェア規約では、ドライバー内蔵5V振動モーターモジュールでも
`VCC-GND`間に100µF程度のバルクコンデンサーを近接配置する方針です。

例:

```text
VCC ----+---- module VCC
        |
      100uF
        |
GND ----+---- module GND
```

電解コンデンサーを使用する場合は極性を確認してください。

## 安全上の注意

- `VCC`と`IN`を取り違えない
- GNDを共通にする
- モーター本体をGPIOへ直接接続しない
- 発熱、異臭、USB切断、リセットを繰り返す場合は直ちにUSBを外す
- 書き込みや配線変更時は、必要に応じてモジュールの`IN`または`VCC`を外して切り分ける
