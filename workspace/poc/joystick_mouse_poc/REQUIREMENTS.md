## 動作

- 起動後約0.5秒はジョイスティックに触れず、中心位置を自動校正する。
- 各軸は中心の停止領域と、正負それぞれ5段階に変換する。
- PC側アプリが10ms周期で、段階`1,2,3,4,5`を`1,2,4,7,11 px`の移動量へ変換する。
- 押し込み中だけポインターを拡大し、離すと起動前のサイズへ戻す。
- PC側アプリ終了時にも起動前のサイズへ戻す。

## 受け入れ条件

- [x] 静止時にポインターが移動しない（Windows実機、利用者確認）。
- [x] 上下左右へ傾けた方向とポインターの方向が一致する（Windows実機、利用者確認）。
- [x] 各方向について、傾きに応じた5段階の速度を確認できる（Windows実機、利用者確認）。
- [x] 押し込み中だけポインターが大きくなる（Windows実機、利用者確認）。
- [x] 押し込み解除時とアプリ終了時に元のサイズへ戻る（Windows実機、利用者確認）。

## 調整対象

- 静止時にドリフトする場合: `joystick_mouse.c`の`DEAD_ZONE`を増やす。
- 5段階を使い切れない場合: `LEVEL_STEP`を減らす。
- 左右または上下が逆の場合: `X_DIRECTION`または`Y_DIRECTION`を`-1`にする。
- 速度感: `host/joystick_mouse_host.py`の`SPEED_PIXELS`を調整する。
- 拡大量: 同ファイルの`WINDOWS_LARGE_STEP`または`MAC_LARGE_STEP`を調整する。
