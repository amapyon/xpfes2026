# PART-03 ジョイスティックマウス PoC

アナログジョイスティックでポインターを5段階の速度で動かし、押し込み中だけポインターを拡大する主催者向けPoCです。ファームウェア単体ではマウスを動かさず、PC側アプリを起動した間だけ動作します。

## ファイル

- `WIRING.md`: 配線図、電圧測定、安全確認
- `REQUIREMENTS.md`: 要件、受け入れ条件、調整箇所
- `joystick_mouse.c`: UIAPduino用ファームウェア
- `host/joystick_mouse_host.py`: Windows/macOS用PCアプリ

## 確認手順

1. `WIRING.md`の電圧・SW測定を行い、安全確認を完了する。
2. Devkitを起動し、このディレクトリで`make`と`make size`を実行する。
3. USBを外した状態で配線を再確認し、`make flash`で書き込む。
4. 再接続後は約0.5秒間ジョイスティックに触れない。
5. `make hidcheck`で1台だけ認識されることを確認する。
6. まず`make app-dry-run`で、静止時`x=+0 y=+0`、各方向で1～5段階、押下時`pressed=1`になることを確認する。
7. 問題がなければ`make app`で実際のポインター動作を確認する。

停止は`Ctrl+C`です。通常終了時は元のポインターサイズへ戻ります。異常終了でサイズが戻らない場合は`make restore`を実行します。ポインターが意図せず動き続けた場合は、まず`Ctrl+C`、反応しなければUSBケーブルを外してください。

## 検証結果

Windows実機で、静止時の停止、傾けた方向への移動、上下左右それぞれ5段階の速度、押し込み中のポインター拡大、押し込み解除時のサイズ復元が想定どおり動作した。電圧の実測値と配線安全確認者は記録されていないため、配線安全確認欄は未確認のままとする。

確認済みのPART-03接続条件は、5Vからの給電とGND共有、VRXから`D1 / A0 / PA2`、VRYから`D0 / A1 / PA1`、SWから`D5 / PC3`である。SWは内部プルアップを使用し、押し込み時Lowとして正常に動作した。VRX/VRYの出力電圧実測値、端子の物理的な並び順、macOS実機動作は未確認である。
