# ジョイスティックマウス PoC 配線

> 状態: **配線安全確認待ち**。PART-03は物理的な端子配列と信号電圧が未確認です。最初はVRX/VRYをUIAPduinoの入力から外し、電源とGNDだけを接続した測定用状態で電圧を確認してください。

## 配線図

```text
PART-03 アナログジョイスティック          UIAPduino Pro Micro CH32V003 V1.4

  GND  o-----------------------------------o GND
  5V   o-----------------------------------o 5V
  VRX  o--------- [1 kΩ] -----------------o D1 / A0  (PA2 / ADC0)
  VRY  o--------- [1 kΩ] -----------------o D0 / A1  (PA1 / ADC1)
  SW   o-----------------------------------o D5       (PC3 / 内部プルアップ)

  USBケーブル ---------------------------- PC
  ※ PD3/D13、PD4/D14、PD5/D15はUSB用のため他用途に使わない
```

## 配線表

| PART-03端子 | UIAPduino基板表記 | ch32fun端子 | 用途 | 補助部品・条件 |
|---|---|---|---|---|
| GND | GND | GND | 共通GND | 直結 |
| 5V | 5V | 電源 | ジョイスティック給電 | UIAPduinoの5V端子へ接続 |
| VRX | D1 / A0 | PA2 / ADC0 | X軸入力 | 1kΩ直列、実測0～5.0V内 |
| VRY | D0 / A1 | PA1 / ADC1 | Y軸入力 | 1kΩ直列、実測0～5.0V内 |
| SW | D5 | PC3 | 押し込み入力 | 内部プルアップ、押下時Low想定 |

## 資源競合

- PA2/ADC0、PA1/ADC1をアナログ入力に使用する。
- PC3をデジタル入力に使用する。
- PD3、PD4、PD5はrv003usb専用として予約する。
- PD1/SWIOは未使用のまま予約する。
- SPI、I2C、PWM、DMA、基板上LEDは使用しない。

## 通電前の必須確認

1. USBケーブルを外す。
2. PART-03実物の印字で`GND / 5V / VRX / VRY / SW`を確認し、外観上の並びをこの表だけから推測しない。
3. UIAPduinoのマイコン電源設定が出荷時の5V設定であることを確認する。
4. まずPART-03のGNDと電源だけをUIAPduinoの5Vへ接続する。
5. VRXとVRYをUIAPduinoから外した状態でテスター測定し、全可動域が0～5.0V内であることを確認する。
6. SWの導通を確認し、押下時にGNDへ接続されることを確認する。
7. USBを再び外し、VRX/VRYへ1kΩ直列抵抗を入れて全配線を行う。
8. 配線確認者が安全確認欄を記入してから通電する。
