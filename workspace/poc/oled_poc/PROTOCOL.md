# USB HIDコマンド仕様

USBはVendor-defined HID Feature Reportを使用します。

- VID:PID: `1209:0001`（共有テスト用。教育目的の試作とワークショップ内テスト専用）
- `1209:0001`は世界で一意ではなく、製品、製造、販売、再配布には使用しない
- Product: `UIAP OLED PoC`
- Report ID: `0x01`
- Report全長: 25バイト（Report IDを含む）
- 未使用バイト: `0x00`
- 図形座標: 左上原点、x=0..127、y=0..63のピクセル座標
- 文字セル: 左上原点、列=0..20、行=0..7。1セルは横6×縦8ピクセル

## PCからUIAPduino

| byte | 内容 |
|---:|---|
| 0 | Report ID=`0x01` |
| 1 | コマンド |
| 2 | シーケンス番号（1..255推奨） |
| 3..24 | コマンド引数 |

| コマンド | 値 | 引数 |
|---|---:|---|
| 出力 | 1 | なし |
| クリア | 2 | なし |
| 全面塗りつぶし | 3 | なし |
| 文字列 | 4 | byte 3=文字セル列、4=文字セル行、5=長さ、6..24=文字列（最大19バイト） |
| 直線 | 5 | byte 3=x0、4=y0、5=x1、6=y1 |
| 矩形 | 6 | byte 3=左上x、4=左上y、5=右下x、6=右下y、7=塗りつぶし |
| 円 | 7 | byte 3=中心x、4=中心y、5=半径、6=塗りつぶし |
| デモ | 8 | なし。バッファ作成後、そのまま出力する |
| 接続診断 | 9 | なし。`0x3C`、`0x3D`を検出して初期化する |

クリア、全面塗りつぶし、文字列、直線、矩形、円はRAMバッファだけを変更します。
OLEDへ反映するには最後に出力コマンドを送ります。

文字は横5×縦7ピクセルです。文字セルは横6×縦8ピクセルで、右1列を
消去して文字間隔を1ピクセルにします。最下段1行もセル間の空きです。
`0x20`～`0x7E`はASCIIグリフ、それ以外の1バイトは5×7の塗りつぶしです。
PC側プログラムは20文字以上の文字列を複数レポートへ自動分割します。選択した
行に収まらない部分は画面外として送信しません。

## UIAPduinoからPC

GET_REPORTの先頭は次のとおりです。

| byte | 内容 |
|---:|---|
| 0 | Report ID=`0x01` |
| 1 | status |
| 2 | 最後に処理したコマンド |
| 3 | 最後に処理したシーケンス番号 |
| 4 | 検出アドレス（未検出は0） |
| 5 | OLED検出済みなら1 |

statusは、0=idle、1=ok、2=bad-command、3=bad-argument、
4=oled-not-found、5=i2c-errorです。

矩形と円の塗りつぶし指定は`0`=輪郭のみ、`1`=内部を塗りつぶす、です。
それ以外の値は`bad-argument`になります。指定を省略するPC側コマンドは`0`を送ります。
