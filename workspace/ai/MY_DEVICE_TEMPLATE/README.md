# device1

受講者が生成AIと相談して作る物理UIデバイスのプロジェクトです。このディレクトリは生成開始時のひな型で、初期状態では外付け部品を使用せず、基板上LEDを消灯したまま待機します。

## 作成前に完成させるもの

1. `REQUIREMENTS.md`に目的、使用部品、動作、完成条件を記載する
2. `WIRING.md`に全配線、GPIO、電源、信号条件、資源競合を記載する
3. `WIRING.md`の設計結果と要確認事項を読み、安全上または物理配線上の問題が残っている場合は停止する
4. ソフトウェア実装上の未確定事項は合理的に決定し、`device1.c`を要件と配線に合わせて生成する

## ビルド

Windowsでは`start-uiap.cmd`、macOSでは`start-uiap.command`からDevkit環境を開始します。`workspace/my/device1`へ移動して実行します。

```text
make
make size
```

ビルド成功だけでは実機動作を確認したことになりません。

## 書き込み

1. USBケーブルを外した状態で`WIRING.md`と実物を照合する
2. 短絡、極性、電源電圧、信号線、未接続端子を目視確認する
3. 書き込み待機の手順に従ってUIAPduinoを接続する
4. 次を実行する

```text
make flash
```

## 実機確認

`REQUIREMENTS.md`の受け入れ条件を1項目ずつ確認し、結果をREADMEまたは別の確認記録へ残してください。異常な発熱、臭い、音、動作、USB切断があれば直ちにUSBケーブルを外します。
