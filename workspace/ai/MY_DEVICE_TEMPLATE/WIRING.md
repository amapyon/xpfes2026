# device1 配線

この文書は、確認済みの`REQUIREMENTS.md`をもとに、UIAPduino Pro Micro CH32V003 V1.4と使用部品の配線を定義する正本です。

確認できない項目は空欄にせず`未確認`と記載します。
今回の構成に存在せず確認自体が不要な項目は`該当なし`と記載します。
`未確認`と`該当なし`を混同しません。

生成AIが`配線案作成可能`と判断しても、人による配線安全確認が完了したことを意味しません。

配線安全確認が`確認済み`になるまで、次を行いません。

* 実物の配線
* 通電
* ファームウェア書き込み
* プログラム生成
* PC側プログラム生成
* 実機動作試験

## 配線安全確認

この欄は、受講者または講師が実際に内容を確認した後に更新します。

生成AIは`状態`を`確認済み`へ変更せず、確認者として生成AI自身を記載しません。

### 確認状態

* 状態:

  * 未確認 / 確認済み
* 確認者:
* 確認日:
* 確認対象:

  * 初回プログラム生成前 / プログラム修正後の再確認
* 再確認対象のプログラム版:

  * 該当なし / （記入）
* 備考:

初回プログラム生成前は、原則として次のようにします。

* `確認対象: 初回プログラム生成前`
* `再確認対象のプログラム版: 該当なし`

プログラム修正によってGPIO、電源、信号、起動状態、停止状態、出力条件など電気的安全性に関係する内容が変わる場合は、配線安全確認を再度行います。

* [ ] 配線表と実際に使用する部品の端子が一致している

* [ ] 電源電圧が確認できている
* [ ] 信号電圧が確認できている

* [ ] 部品の必要電流が確認できている

* [ ] 必要な抵抗を使用している
* [ ] 必要なドライバー回路を使用している
* [ ] 必要な逆起電力・ノイズ対策を行っている
