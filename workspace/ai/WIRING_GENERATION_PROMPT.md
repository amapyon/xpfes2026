# 配線設計のプロンプト

UIAPduino Pro Micro CH32V003 V1.4と、
REQUIREMENTS.mdに記載された部品を使って、
自由制作device1の配線を設計してください。

初心者が短時間で配線でき、
そのままプログラム生成へ渡せるWIRING.mdを作ってください。

## 添付資料

- BOARD_FOR_AI.md
- PARTS_FOR_AI.md
- REQUIREMENTS.md
- MY_DEVICE_TEMPLATE/WIRING.md

REQUIREMENTS.mdに参考演習・PoCが記載されている場合は、
利用可能ならその資料も参照してください。

## このワークショップでの前提

PARTS_FOR_AI.mdに掲載されている配布部品と、
そこに記載された標準的な使用方法は、
講師がワークショップで使用可能であることを確認済みです。

そのため毎回、

- 部品自体が安全か
- 最大定格を一から証明できるか
- 一般的な同名部品のデータシートと一致するか

を再調査する必要はありません。

PARTS_FOR_AI.mdの確認済み情報を正本として使用してください。

ただし、

- 電源とGNDの接続
- GPIOへ接続できる信号か
- GPIOから直接駆動してよい負荷か
- 必要なドライバー・抵抗・ダイオードが使われているか
- GPIO競合
- USB予約GPIO
- 極性

など、今回の組み合わせで生じる問題は確認してください。

## 設計方針

複数の配線方法がある場合は、
質問して止まるよりも次の優先順位で1案を選んでください。

1. 既存の演習・PoCと同じ配線
2. 部品点数が少ない
3. 初心者が間違えにくい
4. GPIO割り当てが単純
5. USBや書き込み機能と競合しない
6. WindowsとmacOSで同じプログラムを使用できる

細かなGPIO選択は生成AIが決めて構いません。

## 必ず確認すること

### UIAPduino固有

- UIAPduino基板表記とch32fun端子名の対応
- PC0 / D2の基板上LEDとの競合
- PD1 / D11をSWIO用として原則予約
- rv003usb使用時のPD3 / PD4 / PD5
- 基板左右の同名7 / 8 / 9を別GPIOとして扱っていないこと

### 配線

- VCC
- GND
- 入力端子
- 出力端子
- 極性
- 必要なプルアップ / プルダウン
- 必要な抵抗
- 必要なドライバー
- 必要な逆起電力対策

PARTS_FOR_AI.mdで確認済みの標準回路がある場合は、
その構成を優先してください。

### GPIOと周辺機能

今回使用するものだけ確認してください。

例:

- ADC
- PWM
- タイマー
- SPI
- I2C
- USB

使用しない周辺機能について、
詳細なチェック表を作る必要はありません。

## USBを使う場合

USBを使用する場合は、

- 使用するUSB方式
- 参考にする演習・PoC
- PD3 / PD4 / PD5の予約

をWIRING.mdへ記載してください。

VIDとPIDはワークショップ共通値`1209:0001`を使用します。Product文字列、Report Descriptor、Report ID、
Reportの各バイトなどのソフトウェア詳細は、
WIRING.mdで決める必要はありません。

これらはPROGRAM_GENERATION_PROMPT.mdで、
確認済み参考実装を基準に決定してください。

## 要確認にする条件

次の場合だけ「要確認」として停止してください。

- REQUIREMENTS.mdに安全上重要な要確認事項が残っている
- 使用するPART-IDが資料に存在しない
- 安全な電源接続を決められない
- GPIOへ直接接続すると危険な負荷について必要な駆動回路を決められない
- GPIOまたは必要な周辺機能が不足している
- USB用GPIOなどの必須資源が競合し、代替GPIOもない
- BOARD_FOR_AI.mdとPARTS_FOR_AI.mdが重要な点で矛盾している
- 極性や端子が不明で、誤配線の危険がある

単に複数のGPIO候補がある、
より最適な設計があり得る、
という理由では停止しないでください。

最も単純な案を選んでください。

## WIRING.mdに記載すること

- 使用部品
- 配線表
- GPIOの用途
- 入力 / 出力方向
- 必要なプルアップ / プルダウン
- 必要な補助回路
- USB使用時の予約GPIO
- プログラム生成へ渡す情報
- 初心者が注意する配線
- 配線前30秒チェック
- 要確認事項

## 配線表

1接続を1行としてください。

UIAPduinoへ接続する信号には、
可能な限り次の両方を記載してください。

- UIAPduino基板表記
- ch32fun端子名

## 配線前30秒チェック

長い安全審査ではなく、
初心者が実際にUSBを接続する前に確認する
短いチェックリストを作ってください。

原則として次の5項目以内にしてください。

例:

- VCCとGNDを逆にしていない
- 部品の向きが合っている
- 配線表とGPIOが一致している
- USB用端子へ別部品を接続していない
- 金属線同士が意図せず接触していない

## 出力

最初に次のどちらかを示してください。

- 配線OK
- 要確認

「配線OK」の場合は、
MY_DEVICE_TEMPLATE/WIRING.mdを使って
完成したWIRING.md全文を出力してください。

「要確認」の場合は、
何を確認すれば配線を決められるかを簡潔に示してください。

プログラムはまだ生成しないでください。
