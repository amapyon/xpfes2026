# 生成AI向け部品情報

この文書は、ワークショップで受講者が自由制作に使用できる部品について、主催者が提示する文字情報の正本です。

生成AIは次の規則に従ってください。

- この文書に記載された確認済み事項と未確認事項を区別する
- 未確認の型番、端子配置、電圧、電流、通信方式を推測で確定しない
- 配線を提案する前に、使用する全GPIOの入出力、ADC、PWM、タイマー、USBとの競合を確認する
- モーター、ブザー、LEDなどの負荷を、定格と必要な保護部品の確認なしにGPIOへ直結しない
- 配線変更前にUSBケーブルを外すよう受講者へ案内する
- 自由制作用プログラムは原則として`workspace/my/device1`へ作成する
- この文書自体を自由制作の一部として変更しない

現時点では、情報が確認・整理できた部品から順次追加しています。記載がない配布部品について、一般的な同名部品の仕様を仮定しないでください。

### 名称

ロータリーエンコーダモジュール

### 型番

未確認（販売上の名称は「ロータリーエンコーダモジュール」）

### 分類

入力

### できること

- 軸を回した方向を入力として取得できる
- 軸を押し込んでスイッチ入力として使用できる
- 回転方向のCW / CCWを判定できる

### 端子

- GND
- S1
- S2
- KEY
- 5V

### 電源・信号条件

- 販売ページ上の動作電圧は5V
- 1周20パルス
- KEYは確認済み演習では内部プルアップを使用し、押し込み時Lowとして読む
- S1 / S2は回転信号として使用する
- 自由制作で使用するGPIOは固定しない
- 自由制作では、GPIOの機能競合と信号条件を配線ごとに確認する

### 数量

参加者1人あたり1個

### 加工状態

未確認

ワークショップではブレッドボードまたはジャンパー線へ接続できる状態で使用する。

### 確認済み事項

- UIAPduino Pro Micro CH32V003 V1.4との組み合わせで使用している
- 購入先の商品ページ上の名称は「ロータリーエンコーダモジュール」
- 端子表記は`GND / S1 / S2 / KEY / 5V`
- 必須演習では次の配線を確認済み
  - GND → GND
  - S1 → D9 / PC7
  - S2 → D8 / PC6
  - KEY → D5 / PC3
  - 5V → 5V
- `01_macro_keyboard`ではGNDとKEYだけを使用する
- `02_rotary_cursor_size`ではS1 / S2 / 5Vを追加する
- `04_rotary_cursor_haptic`でも同じモジュールを使用する
- 必須演習で使用する個体をそのまま自由制作でも使用し、追加の個体は配布しない

### 未確認事項

- 製造元が定めた正式な型番
- 自由制作で別GPIOへ接続した場合の全組み合わせ
- メーカーが保証する最大電流等の詳細電気仕様

### 参考演習・PoC

- `workspace/exercises/01_macro_keyboard`
- `workspace/exercises/02_rotary_cursor_size`
- `workspace/exercises/04_rotary_cursor_haptic`

### 注意事項

- 旧3端子ロータリーエンコーダーのA/C/B配線を、このモジュールへ流用しないこと
- 独立したモメンタリスイッチの配線を、このモジュールのKEY端子へそのまま流用しないこと
- 配線変更前にUSBケーブルを外すこと
- S1とS2を入れ替えると回転方向の判定が逆になる場合がある
- 自由制作では既存のGPIO割り当てを当然の前提とせず、他部品との競合を確認すること
