# Source availability — test package

この検証用ZIPは公開リリース成果物ではなく、正式なソース提供オファーを構成しません。

`setup`が取得する上流情報は`bootstrap.lock`と、実行後に生成される`workspace/deps/VERSIONS.md`へ記録します。

GNU Make 4.4.1について、このテスト版はHomebrew公式arm64ボトルを取得します。対応する上流ソースはGNU Make 4.4.1で、ソースアーカイブの固定SHA-256は次です。

```text
8814ba072182b605d156d7589c19a43b89fc58ea479b9355146160946f8cf6e9
```

最終公開版では、GNU Makeの対応ソースを含む完全な固定上流ソース、パッチ、サブセット生成スクリプト、許可リスト、ビルド手順、対応ソースアーカイブ、SBOM、SHA256SUMSを別途提供してください。
